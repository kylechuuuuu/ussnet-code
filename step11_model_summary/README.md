# 模型总览：边界三明治 × 多中心预训练蒸馏

> 本文件夹把 USSnet 项目的**模型本体**与**两个创新点**整理成可直接用于论文/汇报的材料。
> 日期：2026-10-22 ｜ 所有数字均来自本项目实测（出处见 `EVIDENCE.md`）。
> 状态标记：✅ 已复现/多折；◐ 单折单种子（待复现）；⏳ 运行中；✗ 已证否。

## 0. 一句话

**一个 13.33 M 的窄 ViT 学生**（窗口注意力 + RoPE，63× 压缩自 841.7 M 的超声基础模型），
带**三明治 6 通道头**（base/cautious/amplified）；训练时用**去均值低秩教师特征**做蒸馏（老师只在离线出现），
推理时用**边界证据仲裁**把边界推准，并用 **GT-free 软度统计**做监测/回退。

两个创新点：

1. **多中心侧 —— 预训练模型怎么用**：超声域 FM 的"核心内容"不是 1024 维原始特征，而是**去均值后的低秩结构**（4 维即可）；
   原始 cosine 蒸馏被 DC 主导、近似空转；центered 低秩蒸馏把边界指标抬高 +4.7 bdice。
   **多中心鲁棒性（条件平坦）由架构决定，不由教师知识决定**；教师提供的是精度/边界质量，不是"泛化性"。
2. **边界侧 —— 三明治结构**：一个 backbone 三个版本（base / cautious=erode3 / amplified=dilate4）+ 区间内图像证据仲裁。
   **它的正确用法不是"不确定性估计"**（区间 UQ 已被三类实验证否），而是**边界编辑窗口 + 监测接口**；
   编辑增益 δ 在 6 个训练臂/多折上符号一致（+3.7~+4.3 bdice），是项目中最稳固的机制不变性。

## 1. 两个创新点的关系（论文结构）

```
                ┌─────────────────────────────────────────────┐
  训练期(离线)   │  超声 FM 教师（UltraSAM3 841.7M，永不上线）      │
                │    └─ 冻结特征缓存（17 采集算子 × 视图）        │
                │    └─ 去均值 + 低秩投影（PCA-4/Sketch）        │  ← 创新点 1 的核心操作
                └───────────────┬─────────────────────────────┘
                                │  蒸馏（余弦，每 token 4~64 维）
                                ▼
                ┌─────────────────────────────────────────────┐
  部署期         │  窄 ViT 学生 13.33M（窗口注意力+RoPE）          │
                │    └─ 6 通道三明治头（base/cautious/amplified） │  ← 创新点 2 的接口
                │    └─ 边界证据仲裁（±16px 窗内找脊）            │  ← 创新点 2 的机制
                │    └─ GT-free 软度监测 → 回退/复核              │  ← 安全层
                └─────────────────────────────────────────────┘
```

- **创新点 1 解决"模型从哪里获得域外知识"**：不是把大模型搬上线，而是把它的**去均值低秩特征**蒸进小模型；
  同时给出"什么不能靠它"的边界（鲁棒性=架构，知识≠鲁棒性）。
- **创新点 2 解决"边界怎么定"**：三明治提供受约束的编辑窗口，图像证据在窗口内决定最终边界；
  当证据不足时，监测层报警/回退。两者通过 6 通道头与同一个学生耦合。

## 4. 论文主张（可直接引用的三句话）

1. **"域相关的预训练权重是可以被压缩的知识，但它的可迁移核心是去均值后的低秩结构，而不是全维特征。"**
   （证据：raw-1024 ≈ 无教师；centered-PCA-4 +2.2 Dice/+4.7 bdice；noise 目标反而更差。）
2. **"多中心条件平坦性由架构决定，不由教师知识决定。"**
   （证据：6 臂因果实验全部在噪声内；卷积学生两种配方都 Δ≈−26；ViT 学生所有配置都 Δ≈−0.5。）
3. **"边界的泛化性应由'编辑机制的不变性'来声明，而不是由模型精度来声明。"**
   （证据：仲裁 δ 在 6 个训练臂、5 折、多种条件下符号一致；区间 UQ 全部证否。）
