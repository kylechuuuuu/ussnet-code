# 创新点 2：分割边界 —— 三明治结构

> 目标：在边界"证据不足"（弱对比、斑点、前侧弧）的条件下，给出一个**可交付的边界决策机制**：
> 三态头提供受约束的编辑窗口，图像证据在窗口内决定最终边界，证据不足时监测层报警/回退。
> 状态：✅ 多折/多臂，◐ 条件维待补，✗ 已证否的用法见 §3。

## 1. 问题：边界难以界定

实测（step9 误差解剖，val 31，400 法向点）：

| 量 | 值 |
|---|---|
| Dice / bdice@1px | 96.38 / 35.33 |
| \|t_gt\| mean / p50 / p90 | 3.42 / 1.88 / **8.69 px** |
| 尾部（>10px）占比 | **14.1%**（连续弧平均 35.6 点，≈75–100px 弧长） |
| 角向尾部率 | 前侧 [-120°,-60°) **0.42/0.417**；后侧 0.000 |
| 沿轮廓自相关半宽 | 28.6 px（是**连贯弧**，不是散点） |
| HD95 与尾部弧长相关 | ρ = +0.756 |
| 可用率（Dice≥90 & bdice≥20 & HD95≤10） | in-domain 仅 **7–19%** |

**结论**：边界误差不是随机噪点，是**一条连贯弧上的系统性偏差**；那条弧上真值边界"不写在图像里"（step9 §1）。
⇒ 任何以"图像证据"为核心的修正方法在该弧上有硬上限（这与"错 1.5px RMS ≈ 30 分 bdice"一起解释了指标错位）。

## 2. 机制设计

### 2.1 一个 backbone，三个边界假设

- 最后一个 1×1 分割卷积输出 **6 通道**：`base[0:2]`、`cautious[2:4]`、`amplified[4:6]`；
- `tie_seg_heads()` 把三个头的权重绑成同一组，只保留 logit 偏置（嵌套由构造保证）；
- 监督：base=GT，cautious=erode(GT, 3px)，amplified=dilate(GT, 4px)；半径按 step4 边界指纹**角向调制**（弱证据扇区更宽 ×[0.5,1.5]）；
- 推理：一次前向（共享 trunk）→ 三个 mask；`cautious ⊆ base ⊆ amplified` 用集合运算硬保证；
- 区间 `band = amplified \ cautious` —— **它不是 UQ 估计，而是"编辑窗口"**（见 §3）。

### 2.2 区间内图像证据仲裁（"编辑"）

- 对 base 轮廓的每个法向点，在 **±16px** 内沿法向搜索图像脊（σ=1.5 高斯模糊后的梯度响应）；
- 取 `frac×max` 以上、最靠近零的峰；`maxstep=4` 限制单点移动；
- 变体：`free`（无约束）/ `band_lrn`（限制在学到的区间）/ `veto_lrn`（概率+证据联合）/ `contain`（区间语义）；
- 参数（frac=0.7, maxstep=4, sigma=1.5, 窗 ±16）**冻结自训练集探针**，不在 val 上重调。

### 2.3 监测（GT-free）

| 统计量 | 用途 | 实测 |
|---|---|---|
| `conf_margin` = 0.5 等值面平均 \|2p−1\| | 图级分诊/门控 | 对 gross failure AUROC **0.989–0.990**；域内 τ=0.6234 时 0/31 误报 |
| `ent_loc` = 轮廓 ±2px 平均二值熵 | 逐点风险带 | per-case ρ = **+0.452，31/31 为正** |
| `laminarity` = \|base~cautious\|/周长 | 分诊 | 对 bdice<20 AUROC **0.90** |
| 区间宽度 | **无信息** | ρ(width, \|error\|) = **+0.074** |

## 3. 为什么它不是"不确定性估计"（已证否的用法）

三组独立构造的"边界区间"，全部输给同宽/等面积常数带：

| 区间来源 | cover | 同宽常数带 | Δ | 备注 |
|---|---|---|---|---|
| 三头三明治（arch3h） | 0.679 | 0.7135 | **−0.034** | 等面积各向同性带 **0.873** |
| 双模型（内/外圈） | 0.084–0.110 | 0.19–0.25 | **−0.107 ~ −0.145** | r_err **0.84–0.90**，same_dir 0.89–0.92 |
| 实测视图抖动 | 0.474 | 0.698 | **−0.223** | 负对照（仿射扰动）也为负 |

- 尾部（>10px）覆盖只有 **14.6%**；区间方向与误差方向相反（miss_in 0.22 > miss_out 0.10）；
- 误差是 **epistemic 系统性**的，不是可用"第二个模型/扰动视图"平均掉的方差（r_err 0.84–0.90）；
- **结论**：`band` 的正确定位是**编辑窗口**（限制"边界可以往哪推"），而不是"边界在哪"的概率声明；
  风险声明交给 §2.3 的软度统计。**信息在"概率过渡的软硬"里，不在"区间的宽窄"里。**

## 5. 创新点 2 的正式表述

**可以声明**：
1. **"三明治 = 边界编辑窗口 + 监测接口，而不是不确定性估计器。"**
   （区间 UQ 三类构造全灭：Δ −0.03 ~ −0.22；宽度与误差 ρ=0.07。）
2. **"边界编辑增益对模型训练来源不变。"**（9 臂 δ=+3.7~+4.6；5/5 折。）
3. **"证据不足时可 GT-free 检测并回退。"**（AUROC 0.99；compound_B 78.99→93.42；域内零误报。）

**不能声明**：
- "区间覆盖 GT"（cover 0.679 < 等宽/等面积常数带；尾部覆盖 14.6%）；
- "双模型/多视图区间更优"（Δ 更负、r_err 0.84–0.90）；
- "用区间宽度/分歧修正边界"（24 个门控松弛变体全负；损伤 ∝ 移动点比例）。

## 6. 与文献的差异

| 文献族 | 常见做法 | 本项目差异 |
|---|---|---|
| 边界精修（snap/CRF/level-set） | 事后把边界推向证据 | 我们给出**适用边界判据**（宽窗 −17.7 的反例）与"窗口×证据"的相图假说 |
| UQ / conformal / 集成 | 用方差/集合定义不确定性 | 我们证明边界误差是 epistemic，方差类区间不可用；改用软度统计做风险 |
| 三明治/多任务边界 | 多任务正则 | 我们把它做成**绑定偏置的三态假设 + 推理端仲裁**，并量化"编辑不变性" |
| 选择性预测 | 分类拒答 | 我们做**图级回退 + 局部不编辑**双层选择性 |
